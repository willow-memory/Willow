# Getting help

- **Getting started:** the README's [first five minutes](README.md#your-first-five-minutes)
  walks through every command on a made-up person's files.
- **A question:** open an issue and say what you tried. Every question
  makes the docs better, so none is too small.
- **Something wrong:** open an issue with the *Something is wrong* form.
- **An idea for an add-on:** use the *An add-on idea* form, or add it
  yourself; [CONTRIBUTING.md](CONTRIBUTING.md) says how.
- **A security problem:** never in an issue; see [SECURITY.md](SECURITY.md).

Willow is maintained by one person in their own time, so an answer may take
a few days.
