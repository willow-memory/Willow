`demo/life-box`: `open --piles` lays a life the way a person keeps it, a folder per matter, each its own pile with its own box under the one key made for them (a folder holding only a folder is walked through, loose files are a pile). `ask` bites every pile's box, deals what they served out in turns by fair-merge's rule (up to ten a question) and proposes each passage in the box that served it; `decide` and `recap` walk every box and the recap names each answer's pile. A folder's name stops being a word every passage in it holds for free, so Bernadette's scone recipe is offered first in its own pile and sealed; a question that names the folder alone ("on the kindle") loses it.
