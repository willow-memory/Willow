`readme`: the add-on list's topic words and nearest entries stand for the
week, kept in adapters/stdlib/readme/week.json, so a pull request adding an
entry or editing any card no longer moves other entries' lines and makes
every other open pull request's list stale; a new entry is worked out
against the week's entries and itself, and counts from the next week.
Install and online facts and an author's own tag stay read from the card.
restack settles the file as it does the list
