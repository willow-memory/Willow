`mutants`: a break is no longer judged by the code of the break before it. A test that runs `python -I` ignores `PYTHONDONTWRITEBYTECODE` and writes `__pycache__` into the copy anyway, so a later break the same size, written in the same second, imported the earlier one's cached code: die-namic-games' binder tests, which import through `python -I`, had one break reported killed by the failure of the break before it. After each break is written, and after it is put back, every `__pycache__` in the copy is removed and the file is given a fresh, later whole-second mtime.
