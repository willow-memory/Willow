`demo/pools/trace/trace.py stack`: stacks of the grid run on a box that carries on from step to step, the same row a step, and a step's output hashed with the run's own folders and the time of day taken out, so a step alone can be held to the same step in company. Tried on a made-up pile: 14 of 351 steps are not steady alone, and of the rest ten print something else in a stack of every step.
