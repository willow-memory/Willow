`new-kinds`: kinds of file in a stack's folders that no step reads yet, each with the readers that took some of them, tried on copies of a few beside a file of nonsense, so a reader that takes anything isn't mistaken for a fit; `--leave` keeps a kind quiet. The canvas uses its trial to offer readers for files the kernel already reads as plain text (.json, .csv, .jsonl) when a reader knows their shape
