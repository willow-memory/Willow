`robinhood`: your Robinhood account as dated files, read through Robinhood's own MCP server and never traded on. It calls six read tools and no others (no argument names a tool, so the server's order, cancel and watchlist tools can't be reached), skips a listed tool the server marks as changing anything, writes each answer under its day with its SHA-256 on a log, account numbers to their last four digits, and keeps nothing of the sign-in. A stack beside it reads the account's history back.
