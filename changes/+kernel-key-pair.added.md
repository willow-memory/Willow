`kernel.py`: a seal by a key pair (docs/design/key-pair.md, stage 1). `pair` gives a box an Ed25519 pair, the private half in a new file and the public half in the box; `seal` and `decline` then sign, and a signed seal is checked with no secret, so the key can live where nothing that asks questions can read it. `rekey` signs once for every seal and No made with the old key, after which the old key is not read. One rule for checking (no S of L or more, no point of small order, no cofactor), held by `vectors/ed25519.json`; `bite` checks only the seals that name its question. The ports don't check a signed seal yet
