index-cache keeps the index of a list's files where they are kept (`--from @LIST`), and of everything a box reads, its pile and every source (`--box BOX`), named as the kernel names the box's passages. So a box laid from pointers (`init --from`) is answered from an index too: claude-code's hook checks an index against the box's whole manifest, and its `setup` prints the `--box` line. A check reads again only the files whose details on disk moved (size, modification and change times, inode; a file changed as the last run began is always read), and knows its index whole the same way: on cpython's 9,425 files, under a second where it took seven. batch-ask's scan gains `build_from`, the index of passages already read.
