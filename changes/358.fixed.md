`ai-code-tracking`, `codebase-memory`, `jeles` and `nestor` no longer write beside a database they read: each opened it with `mode=ro` alone, which on a database in WAL mode leaves a `-shm` and `-wal` file in the person's folder (the C library writes them, so the add-on guard couldn't see it). Each now opens read-only and immutable, as `bookmarks`, `texts` and `zotero` already did, with a test that a WAL database's folder is left as it was.
