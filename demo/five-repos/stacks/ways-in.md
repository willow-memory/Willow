# the five, askable from anywhere

Every way in that Willow prints a setup for, run on the box over the five
repos. Each step either answers a question in that way's shape or prints
the lines that register it.

## answers in a shape a tool reads
- pipe -- --box {box} --grep "who may approve"
- plain -- bite --box {box} "what never leaves the machine"
- launcher -- --box {box} --format lines "where is the vault"
- deep-links -- --box {box} "source code never leaves the machine"

## the setup each editor and shell wants
- vim -- --box {box}
- vscode -- --box {box}
- emacs -- --box {box}
- jetbrains -- --box {box}
- shell -- script bash
- browse -- launcher --box {box}

## every host that takes an MCP server
- hosts -- list
- hosts -- show claude-code --box {box}
- hosts -- show cursor --box {box}
