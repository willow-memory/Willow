# What was said before the runs

**Written 2026-11-12, before the laptop, the phone or Kaggle had run
[machine.py](../machine.py) on anything but its tests.** A box apart
from the study's verdict box, so a guess is never read as a verdict.
It is a scratch box under a scratch key, made by the cloud session,
outside this repository; what is kept here is a copy of its record and
what is needed to hold that copy to it. The maintainer's key was not
used and nothing here is sealed.

| file | what it is |
|---|---|
| [claims.txt](claims.txt) | twelve claims, each with how likely the cloud session thought it, one a line. The record keeps only each claim's SHA-256, so the words are kept here |
| [record.jsonl](record.jsonl) | the box's record as it stood: row 0, twelve `wager` rows (rows 1 to 12, in the order of claims.txt), then five rows of what was chosen and ruled out, with what would reopen each |
| [tip.json](tip.json) | where that record ended, by the tip-pin add-on: 18 rows. A row added later, or one cut, shows against it |

The add-ons used, each as its card says: **forecasts** for the wagers
(a wager is settled only by a seal, so none of these is settled and
none is scored); **decisions** for the choices and the noes;
**tip-pin** for the tip; **merkle**, whose root over the 18 rows was
`59449a9f5ac0cd586e31062cc08d998b022eb9605ea6a751a21169e83b089ed6`,
and which proved row 3 from five hashes.

The wagers are the session's, not the maintainer's. Whether one came
true is the maintainer's to settle on a box of their own, with the
forecasts add-on's `settle` and their seal; this copy is what to
settle against. A coin at even odds scores 0.25; the nearer 0 the
better.

Not used, and why: **predict** grades what a question to a box will
come to (sealed, served, nothing found), which is another kind of
guess from these.
