# a smallholding

A herd book, the veg beds and the farm's drives, noted by date. Run it at the
start of the month. The mileage year starts on 6 April, the UK tax year; drop
`--year-start` for a calendar year.

    python adapters/stdlib/stack/stack.py --box DIR --stack adapters/stdlib/stack/examples/smallholding.md
