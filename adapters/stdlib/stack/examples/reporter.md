# a local reporter's story folder

Records requests, interview notes and the figures each source gave. Run it
before filing. `--law` sets the clock for answers: `us` here, or uk, au, ca,
nz or ie.

    python adapters/stdlib/stack/stack.py --box DIR --stack adapters/stdlib/stack/examples/reporter.md
