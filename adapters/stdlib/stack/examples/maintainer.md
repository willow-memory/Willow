# a small library's maintainer

A project's code, its maintainers' call notes and a log of the time put in.
Run it before the next call. `advisories` lists the locked dependencies
until it is given a downloaded advisory database: add `--db OSV_DIR` to its
line to match them.

    python adapters/stdlib/stack/stack.py --box DIR --stack adapters/stdlib/stack/examples/maintainer.md
