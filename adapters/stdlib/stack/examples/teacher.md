# a teacher's class folder

One class's syllabus, gradebook, register and the texts being weighed for it,
all kept on the teacher's own machine. Run it on Sunday evening. Raise or lower
`--below` to the mark the department calls behind.

    python adapters/stdlib/stack/stack.py --box DIR --stack adapters/stdlib/stack/examples/teacher.md

## who needs a word this week
- gradebook -- --box {box} --below 60
- attendance -- --box {box} --by week

## what the class has coming
- syllabus -- --box {box}

## which texts will they manage
- reading-level -- --box {box}
