**III.6 — The core reaches nothing that extends it.** What extends the system uses its core; the core never loads, calls on or waits for an extension, and depends on nothing beyond the platform it runs on. With every extension removed it does the same work, the same way. A core that leans on an extension has widened its reach by the extension's (§0.3).
